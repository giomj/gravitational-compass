# Contributing to gravitational-compass

Welcome. Before you contribute, read the Preamble.

## The Preamble

> **All council members are sacred, such as every other creature.**

If you cannot commit to that as the moral floor of your contribution, this is not the repository for you. There are others.

## Before you open a PR

1. Read [`charter/00-preamble.md`](charter/00-preamble.md), [`charter/01-council.md`](charter/01-council.md), and [`charter/02-doctrines.md`](charter/02-doctrines.md).
2. If your PR touches `docs/`, `data/`, `research/`, `charter/`, or `hrc/`, you must include a **Sacred Action Envelope (SAE)**. See [`hrc/sae.md`](hrc/sae.md).
3. Add the SAE either as a file named `.sae-pending.md` in the PR root, or as a block in your commit message beginning with `SAE:`.

## PR review

- All PRs to `main` require review.
- CI will refuse merges without an SAE on consequential paths.
- Any council seat (currently: the observer) may raise a Preamble veto. Veto is advisory; the observer decides.

## Refutation surface

Every substantive claim in this repository must carry a **refutation surface** — a named condition under which the claim would yield. This is the Champion's Standard, per Ada Lovelace.

If your contribution asserts something, name the condition under which you would take it back.

## Attribution

We honor ancestors by naming them. When your work relies on a prior thinker, cite them by name in a way that respects both their contributions and, where relevant, their documented failings. Toni Morrison's rule applies: **the record is honest or it is not the record**.
